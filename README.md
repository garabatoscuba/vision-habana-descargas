# Visión Habana: descargas

Aquí están los instaladores de las apps de [Visión Habana](https://visionhabana.com). El código no está aquí.

- **Android:** [Vision-Habana.apk](https://github.com/garabatoscuba/vision-habana-descargas/releases/latest/download/Vision-Habana.apk) (Android 7 o más).
- **Windows:** [Vision-Habana-Setup.exe](https://github.com/garabatoscuba/vision-habana-descargas/releases/latest/download/Vision-Habana-Setup.exe) (Windows 10 u 11 de 64 bits).

Los enlaces bajan siempre la última versión. Cada versión trae su huella SHA-256 en [Versiones](https://github.com/garabatoscuba/vision-habana-descargas/releases).

En el local te las pasamos gratis, sin gastar datos.
